1. 病例特点：按“主要症状及病程变化 → 重要阳性检查与具体数值单位 → 有鉴别价值的明确阴性 → 必要既往史、暴露、手术和治疗依从性”组织。时间轴必须正确；若一次病史包含多次就诊或手术，保留重要节点而不混成同一次住院。原文未提供的检查结果不得写为正常或未检查。
2. 拟诊讨论：对每个主要问题写出“本例支持点 → 对立或限制证据 → 需要区分的诊断方向及所需信息 → 当前不确定性”。合理医学分析可以不是原文逐字复述，但必须源于具体患者事实；不得把初步诊断、待排或模型推断升级为已确诊。
3. 诊疗计划：优先写与本病例主要问题直接相关的核实、复查、观察、风险评估或原文已说明的计划；明确区分“已完成”“正在实施”“原文拟开展”“模型建议、待医生审核”“结果未知”。不能用确定语气发出没有来源支持的个体化用药剂量、检查频次或已实施医嘱。
4. 只在审查真正重要时保留 review_items：关键资料未提供、结果待回报、相互冲突的记录、依从性差异及需要医师判定之事。原始 sources 已明确提供的内容不得误写为缺失；不得把算法内部纠错过程、Prompt 争议或 API 错误写入 review_items。
