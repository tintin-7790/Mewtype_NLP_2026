# Mewtype：首次病程记录优秀写法研究笔记（2026-11-24）

> 研究目的：**研究语法结构、病程逻辑、证据关联及可追溯依据的写法**，不复制真实患者的病例全文，不把公开临床病例或教学示例作为新患者的事实证据。
>
> 资源属性：公开规范与医学教育文章的**原创概括** + 本包原创合成案例；不是临床治疗指南，也不是医学诊断模型。

## 2. 三段正文各自的逻辑职责

### 病例特点：把病人从一般病史中“识别出来”
- 先写对当次就诊真正重要的主诉和演变，而不是复制所有入院记录。
- 用最简短的时间线体现频次/程度/部位/诱因/缓解因素的改变。
- 同一检查保留“时间+项目+数值+单位+来源层级”；既往与本次不能互换。
- 只写有鉴别意义、来源明确的阴性事实；未知≠否认。
- 共病进入正文要能说明与当前判断的联系，否则不列。

### 拟诊讨论：让读者知道结论依据何在，什么尚未确定
- 每个关键问题至少能回指本例一个可核验支持事实。
- “支持”“明确反对”“证据不足”是三种不同关系，不得混用。
- 鉴别优先关注会改变临床判断或处理的候选，不为凑数增加罕见病。
- 既往诊断记载证明的是“病历曾这样记录”，不自动证明本次诊断为真。
- 不同时间、不同场所、不同单位的结果不应合并成同一检查。

### 诊疗计划：一个待解决问题，对应一个具体核实/检查/监测目标
- 以问题驱动，逐条说明检查或观察要解决何种不确定性。
- 将“原始资料已实施”“原文已计划”“模型可考虑建议（需医生判断）”“状态未知”分清。
- 不因示例里出现某治疗而给当前患者复制药名、剂量、频次。
- 诊疗计划允许审慎条件性建议，但其依据不能虚构为已有医嘱。

## 3. 比赛额外两部分：evidence / review_items

- `evidence` 由**当前病例 Sources**提供，优先3–5条互补要点；若素材不足宁可少于3条，不能凑数。
- `kind=fact` 表示原文确实记载该说法，不代表临床推断已被验证；`kind=inference` 表示有患者事实依据且保留不确定性的归纳。
- `source_ids` 是外键，必须能在当前输入中找到；规则卡、优秀范例、指南均不得成为 `source_ids`。
- `review_items` 记录可以核实的缺失、矛盾、未知状态，不是无限枚举检查项目的清单。

## 4. 证据关系模型（可作为 Shared Clinical Memory 的基本边类型）

核心：`Source → Fact → ClinicalProblem → Differential / PlanGoal`。

- `supports`：现有事实支持某个判断；支持不是证明。
- `contradicts`：明确相反的患者证据，须有原文直接支撑。
- `limits`：现有事实或证据边界限制确定性，未必直接反对。
- `missing_discriminator`：缺失的区分性资料，不能倒推该检查未完成。
- `observed_at`：把值与时间绑定。
- `reported_by`：区分患者自述、家属、检查原报告。
- `status_of`：区分 completed/ongoing/planned/unknown。
- `plan_for`：把拟开展措施绑定到本次临床问题。
- `supersedes`：记录有效更正，不抹去审计链。

完整共13类关系见 `evidence_relation_rules.json`。这是一套针对 Mewtype 设计的数据关系约束，**不是已证实的患者知识图谱**。

## 5. 从公开案例/点评中学到、但不应照抄的内容

- 心血管专科：介入过程的日期与治疗部位、症状变化、依从性、检查结果要能对应；“曾有PCI”本身不能替代本次胸痛原因分析。
- 高龄肾病相关案例：资料很多，但本次问题和重大共病的因果关系需要明确证据，尤其不能把既往肾病患者的用药方案复制到其他病历。
- 优秀案例点评常提出：删除重复现病史，补充有针对性的限制信息；诊疗计划要服务鉴别和风险监测。
- 写作技巧是结构化的，而不是把某篇现成病历放进Prompt照着改。

## 6. 素材质量等级与许可处理

1. **最高优先：** 权威规范条文指导结构；不作为患者事实。
2. **次优：** 医院评价标准和教学点评指导质量；不当作最新诊疗指南。
3. **直接用于程序的素材：** 本包自编、明确标记的原创合成病例与规则卡，不包含真实患者数据。
4. **未来如需真实优秀病历：** 必须有明确可再利用授权、去标识化、避免再识别、校验医学准确性与版本，才考虑加入。仅“公开可浏览”并不等于允许全文复制打包。

## 7. 这次研究有哪些局限

- 尚未在真实 Qwen A/B 上验证规则卡是否提高了比赛医学评分。
- 4份合成示例是写作/核验的测试夹具，不构成某疾病的正式诊疗指南。
- 未对公开案例中的具体诊疗建议作指南级证据审核，所以没有把这些建议存为可直接执行的医嘱模板。
- 竞赛最终的医学评价需要由合格临床评委判断；规则卡不能替代事实核验。
